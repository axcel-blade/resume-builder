## About Vita Forge

**Vita Forge** is a comprehensive career-tools platform for building professional resumes and cover letters. It provides:

- ✨ **Resume Builder** - Create ATS-friendly resumes with live A4 preview
- 📝 **Cover Letter Writer** - Guided form with tone selection
- 🔒 **User Profiles** - Secure user accounts with PostgreSQL storage
- ☁️ **Cloud Sync** - Profile API (Prisma/PostgreSQL when configured)

## Getting Help

### 💬 Support Channels

1. **GitHub Issues** - Report bugs, request features
2. **Documentation** - Check the docs folder for detailed guides
3. **Code Review** - Ask questions in PR discussions

### 🐛 Bug Reports

When reporting a bug, please include:

- Steps to reproduce
- Expected vs actual behavior
- Browser/OS version
- Console errors (F12 → Console)

### ✨ Feature Requests

Suggest improvements with:

- Use case description
- Proposed implementation approach
- Impact assessment
