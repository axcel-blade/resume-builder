# Frontend Roadmap

This roadmap focuses on the VitaForge frontend experience: editor UX, accessibility, export flows, and product polish.

---

## In Progress

- [ ] Accessibility refinement across the resume and cover-letter editors
- [ ] Print/export quality improvements for multi-page documents

---

## Planned

### Resume Builder

- [ ] Additional resume templates (minimal, timeline, two-column)
- [ ] Drag-and-drop section reordering in the editor
- [ ] Per-section visibility toggles
- [ ] Accent colour picker with presets
- [ ] Font family selector
- [ ] Character and word count indicators

### Cover Letter Writer

- [ ] Multiple tone options
- [ ] Opening paragraph variant selector
- [ ] Company name and role autofill from resume data
- [ ] Saved drafts via localStorage

### Platform

- [ ] Unified profile page for resume and cover letter
- [ ] Dark mode support
- [ ] Keyboard navigation improvements
- [ ] WCAG 2.1 AA compliance audit
- [ ] Progressive Web App support

### Export

- [ ] Plain text export for resume and cover letter
- [ ] Print-optimised stylesheet improvements
